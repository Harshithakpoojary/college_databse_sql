 Aggregate Functions Used

### COUNT()
COUNT() counts the total number of student records in the students table. It is also used with GROUP BY to count students in each department.

### AVG()
AVG() calculates the average CGPA of the students. It is also used with GROUP BY to calculate the average CGPA for each department.

### MAX()
MAX() finds the highest CGPA among all students.

### MIN()
MIN() finds the lowest CGPA among all students.

### SUM()
SUM() adds all the CGPA values of the students and gives the total CGPA.

## GROUP BY
GROUP BY groups records based on a column, such as department. It is used with aggregate functions
